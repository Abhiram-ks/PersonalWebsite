Portfolio Project(💼)

- Project Overview
This Portfolio Website is a responsive and cross-platform application designed to showcase my expertise as a Flutter Developer with a background in civil engineering and a strong command of front-end technologies. Built with HTML, CSS, and JavaScript, it presents a clean, modern UI optimized for both web and mobile devices.
The site highlights my technical skills, featured projects (including mobile apps and design-focused web interfaces), and includes sections like About Me, Skills, Resume, and Contact. It’s not only a personal brand hub but also a demonstration of my commitment to writing clean, maintainable code and delivering visually polished, user-friendly experiences.

- Key Features(🚀)
* Responsive Design – Fully optimized for desktops, tablets, and mobile screens
* Mobile-Friendly Layout – Smooth UX and fluid layouts on all devices
* Project Showcase – Highlights Flutter apps and civil-engineering related solutions
* Resume Section – Downloadable resume with live career info
* Contact Form – Easy-to-use form with validation for direct communication
* Light/Dark Mode (optional) – For improved accessibility and user preference
* Custom UI/UX – Modern visuals with smooth transitions and interactive elements

- Tools & Technologies:
HTML | HTML5 | CSS | JavaScript | Responsive Web Design (RWD) | Version control and deployment | VS Code | Bootstrap
